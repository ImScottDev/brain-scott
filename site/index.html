Como funciona

3 passos. 5 minutos.

Você responde uma pergunta. O Claude faz o resto.

01

Instale o Obsidian + Claude Code

Obsidian é grátis. Claude Code roda no terminal. Ambos em qualquer OS.

02

Cole o prompt e responda sobre você

Ele pergunta o que você faz, o que escapa, e se quer incluir vida pessoal. Algumas frases bastam.

03

Vault pronto no Obsidian

Pastas, CLAUDE.md, skills e memória — tudo criado e aberto. Rode /diario amanhã de manhã.
